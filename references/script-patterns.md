# Script patterns (studied from the reference SRT; never copy its wording)

The reference "Why You'd Never Want To Meet A Sperm Whale" runs 9:59, 1,682 words (168 wpm), 39 uses of "you". Use it only to learn rhythm and structure. Every script must be written fresh: new rule, new sensory sign, new jokes, new comparisons, new closing line. If the user picks an animal the reference already covered (sperm whale), the script must take a different angle (see section 5).

## 2. Devices that make it work (patterns, not lines)

- **The rule + the body sensation.** The hook states a comforting rule in 2-3 short checks, then breaks it with a sensation felt in the body (not seen). The same sensation is explained mid-video ("that was ..."), and the rule returns at the end with a twist of meaning.
- **Concede, then escalate.** The reframe agrees with the audience's usual fear ("yes, X is dangerous"), then lists three escalating claims for this animal, the last one the most shocking.
- **Every number gets a body-scale comparison** in the next breath (vehicle, animal count, household object, your own body, your own breath-hold). Never two raw numbers in a row.
- **Chapter hand-off questions.** Each chapter ends on a plain question that the next chapter answers in its first 2-4 words.
- **One dry aside per 40-60 s.** Short, understated, usually a modern everyday comparison (receipts, rooms, kitchens, flies, volume). 5-7 per video. They come right after a hard fact, never inside it.
- **"You" is the camera.** The viewer is placed in the water at the hook, payoff, options, twist and close; the middle chapters can be "it" focused.
- **Options chapter rhythm.** "You could [option]." -> one fact that kills it -> one dry line -> next. The verdict is one blunt sentence.
- **Twist pair.** Twist 1 lowers the threat (it barely notices you, with a calm real-world example). Twist 2 flips it (humans did the damage: numbers before/after, what threatens it today).
- **Ecosystem as a reward.** A 3-4 step cause chain (eat deep -> release near surface -> feeds X -> pulls carbon) with one big number and one human-scale line.
- **Close in under 25 s.** Restate the rule, admit it's mostly true, end on one image of the animal far away still doing its thing.

## 4. Originality rules (apply to every script)

1. Never reuse a sentence, joke, analogy or closing line from the reference or any previous script on this channel.
2. The rule, the sensory sign and the closing image must be specific to THIS animal's real biology (blue whale: the sun going out = the mouth; not a knocking in the chest).
3. Jokes come from this animal's facts, not from a joke bank.
4. Use the brand's own opener (Dive Log), callback line and CTA from brand.json; never "Picture this", never "I do actually read them", never another channel's name.
5. Before writing, list 5 angles the reference (or any existing video on the same animal) used, and choose different ones for the hook, payoff, options jokes and close.
